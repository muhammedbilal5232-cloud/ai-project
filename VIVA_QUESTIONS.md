# Viva Questions and Answers

**1. What is Artificial Intelligence?**  
Artificial Intelligence is a branch of computer science that develops systems capable of performing tasks that normally require human intelligence.

**2. What is Machine Learning?**  
Machine Learning is a method in which computers learn patterns from data and use them to make predictions.

**3. What is handwritten digit recognition?**  
It is the process of identifying numerical digits written by a person.

**4. Which dataset is used in this project?**  
The built-in handwritten-digits dataset provided by Scikit-learn.

**5. What is the size of each dataset image?**  
Each image is 8 × 8 pixels, giving 64 pixel values.

**6. Which model is used?**  
A Multi-Layer Perceptron (MLP), which is an Artificial Neural Network.

**7. What is training data?**  
Training data is the set of examples used to teach the machine-learning model.

**8. Why do we use testing data?**  
Testing data helps estimate how well the trained model predicts examples it has not seen during training.

**9. What is Streamlit?**  
Streamlit is a Python framework used to create interactive web applications.

**10. What is image preprocessing?**  
It is the process of preparing an image before giving it to a model. Here, the drawing is converted to grayscale, resized, and its pixel values are scaled.

**11. Can the model always predict correctly?**  
No. It can make mistakes when handwriting is unclear or differs from the training examples.

**12. What is a limitation of this project?**  
It uses small 8 × 8 images and recognises only single digits from 0 to 9.

**13. What is the role of NumPy?**  
NumPy is used for numerical arrays and pixel-value operations.

**14. What is a neural network?**  
A neural network is a machine-learning model made of connected processing units arranged in layers.

**15. How can this project be improved?**  
It can be improved by using a larger dataset, better preprocessing, or a convolutional neural network.
